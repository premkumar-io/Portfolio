# Portfolio Testing Plan

## Functional Testing
- Navigation works.
- All routes load.
- Resume opens/downloads.
- GitHub links work.
- LinkedIn links work.
- Project links work.
- Contact form works if implemented.
- Form validation works.
- Mobile menu works.
- Theme toggle works if implemented.
- 404 route works.

## Responsive Testing
Test:
- iPhone-sized viewport
- Android-sized viewport
- Tablet
- Laptop
- Desktop
- Large monitor

Verify:
- No horizontal scroll.
- No clipped content.
- No overlapping elements.
- Buttons remain tappable.
- Text remains readable.

## Accessibility Testing
- Keyboard-only navigation
- Screen reader basics
- Focus visibility
- Form labels
- Contrast
- Reduced motion

## Performance Testing
Check:
- Initial page load
- Image sizes
- JavaScript bundle
- Layout shifts
- Largest contentful paint
- Interaction responsiveness

## Browser Testing
At minimum:
- Chrome
- Safari
- Firefox
- Edge

## Final QA
Before deployment:
- Run lint
- Run type checking
- Run production build
- Fix all errors
- Verify every external link
- Verify metadata
- Verify favicon
- Verify social preview
- Verify resume
