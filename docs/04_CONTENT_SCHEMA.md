# Portfolio Content Schema

The UI must be data-driven so content can be updated without rewriting components.

## Profile
```ts
{
  name: "Prem Kumar",
  title: "Software Engineer",
  location: "India",
  summary: "...",
  email: "...",
  phone: "...",
  github: "...",
  linkedin: "...",
  resume: "/resume/Prem-Kumar-Resume.pdf"
}
```

## Experience
Store:
- Company
- Position
- Type
- Location
- Dates
- Description
- Responsibilities
- Achievements
- Technologies
- Company URL

## Projects
Store:
- Slug
- Title
- Category
- Short description
- Full description
- Problem
- Solution
- Features
- Technologies
- Role
- Challenges
- Outcome
- GitHub
- Live demo
- Images
- Featured flag

## Skills
Group skills into:
- Languages
- Frontend
- Backend
- Databases
- AI/ML
- Cloud/DevOps
- Tools

Do not use fake proficiency percentages.

## Education
Store:
- Degree
- Institution
- Location
- Start date
- End date
- Grade/CGPA if desired
- Relevant coursework if useful

## Certifications / Training
Store:
- Name
- Provider
- Date
- Credential URL
- Credential ID if applicable

## Achievements
Use only verifiable achievements.

## Writing Rules
- Be concise.
- Lead with outcomes.
- Use measurable results when truthful.
- Avoid buzzword stuffing.
- Avoid unsupported claims.
- Prefer real engineering details.
- Keep recruiter readability high.
