# Portfolio Feature Specification

## Must Have
- Responsive navigation
- Hero section
- About
- Skills
- Projects
- Experience
- Education
- Internships
- Certifications
- Achievements
- Resume download
- Contact section
- GitHub/LinkedIn links
- Footer
- SEO
- Responsive design
- Accessibility
- 404 page

## High Value
- Dedicated project detail pages
- Project filtering
- Project search
- Copy email button
- Download resume tracking
- Active section navigation
- Scroll progress indicator
- Back-to-top
- Command/quick navigation
- Print-friendly resume page
- Social preview metadata

## Optional
- GitHub contribution section
- GitHub repository cards
- Blog/notes
- Testimonials
- Availability status
- Contact form backend
- Analytics

Do not add optional features merely to make the website look complex. Every feature must improve recruiter/user experience.

## Project Detail Page
Include:
1. Hero
2. Overview
3. Problem
4. Solution
5. Features
6. Architecture/technical approach
7. Tech stack
8. Challenges
9. Results
10. Screenshots
11. GitHub/live demo
12. Related projects
