# SEO, Accessibility & Discoverability

## SEO
Implement:
- Unique title per page
- Meta description
- Canonical URL
- Open Graph metadata
- Twitter/X metadata
- Sitemap
- robots.txt
- Semantic HTML
- Descriptive URLs
- Structured internal linking

## Person Structured Data
Where appropriate, use JSON-LD for:
- Person
- WebSite
- CreativeWork/SoftwareSourceCode for projects when valid

Only publish factual information.

## Accessibility
Target WCAG 2.2 AA principles.

Checklist:
- Keyboard navigation
- Visible focus
- Screen-reader-friendly labels
- Heading hierarchy
- Form labels
- Error messages
- Alt text
- Accessible contrast
- Reduced motion
- No keyboard traps
- No flashing content

## Social Sharing
Create a strong Open Graph image:
- Name
- Professional title
- Simple visual identity
- Minimal text

Avoid overly busy social cards.
