# Portfolio Documentation — Antigravity Setup

## What This Folder Contains

This documentation package is the blueprint for building a production-grade personal portfolio.

### Files
- `01_PRD.md` — Product requirements
- `02_ARCHITECTURE.md` — Technical architecture
- `03_DESIGN_SYSTEM.md` — Visual/UI system
- `04_CONTENT_SCHEMA.md` — Content structure
- `05_FEATURES.md` — Feature requirements
- `06_RULES.md` — Engineering/design rules
- `07_SEO_ACCESSIBILITY.md` — SEO and accessibility
- `08_TESTING.md` — QA plan
- `09_DEPLOYMENT.md` — Production deployment
- `10_PHASES.md` — Development roadmap
- `11_ANTIGRAVITY_MASTER_PROMPT.md` — Main implementation prompt

## How To Use

1. Put this documentation folder inside your portfolio project.
2. Open the project in Antigravity.
3. Give Antigravity the `11_ANTIGRAVITY_MASTER_PROMPT.md` as the primary instruction.
4. Tell it to read the other documentation files before implementation.
5. Provide the actual resume PDF and portfolio content.
6. Replace placeholders with verified personal information.
7. Build phase by phase.
8. Run the testing checklist before deployment.

## Recommended Content Assets

Prepare:
- Resume PDF
- Professional photo if desired
- Project screenshots
- Project demo URLs
- GitHub profile
- LinkedIn profile
- Email
- Experience details
- Internship details
- Education details
- Certifications
- Achievements
- Professional domain

## Golden Rule

Do not add features just because they look impressive.

Every feature should improve:
- Recruiter usability
- Professional credibility
- Project storytelling
- Accessibility
- Performance
- Maintainability

The portfolio should be simple to understand and difficult to forget.
